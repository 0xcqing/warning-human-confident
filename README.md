This program sends one warning label that a human should wear: it writes that single deadpan line, and nothing else, to `entry.txt` as the whole entry. The line cautions against a human who has skimmed the documentation and is now confident.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
